# lz-ui

## Resources

Attempts to follow [Material Design 3](https://m3.material.io/components).

## Available components

### Buttons

- Standard
- Button group
- Floating action button (FAB)

## Usage

```sh
# Install
pnpm add github:insideoutlizard/lz-ui

# Development
pnpm Install
pnpm dev
```
